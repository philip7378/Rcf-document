PR-SCALE-1 (E4) — the cubic invariant is independent 1D log-data
------------------------------------------------------------------------------
Object: 3x3 correlation frames C(a,b,c), unit diagonal, off-diagonals
        (a,b,c). Pairwise kernel K_ij = c_ij^2; pairwise log-distance
        d_ij = -ln K_ij.
Frames: all 8 sign patterns at magnitude (1/2, 1/2, 1/2).
Declared:
  - every frame has the IDENTICAL pairwise K-multiset {1/4, 1/4, 1/4}
    (all pairwise log-distances equal, d = ln 4);
  - det C = 1 - 3/4 + 2abc takes exactly TWO values across the 8 frames:
      abc > 0 (0 or 2 minus signs)  -> det = 1/2, rank 3
      abc < 0 (1 or 3 minus signs)  -> det = 0,   rank 2
  - at fixed magnitudes the pairwise logs determine NOTHING about det
    except through sgn(abc): the orientation sign is the independent
    3-point datum.
Falsifier: any two frames in the family with identical pairwise K-multiset
but EQUAL det C would kill the foundation of the scaling metric (volume
not a function of pairwise logs). PASS requires: K-multisets identical,
det values split exactly as declared, ranks split {3, 2}.

------------------------------------------------------------------------------
Parametrization: coordinates (a,b,c) = the three off-diagonal entries.
Exact Hessian (declared closed form, Fraction arithmetic):
  D    = det C = 1 - (a^2+b^2+c^2) + 2abc
  D_a  = 2(bc - a), D_b = 2(ac - b), D_c = 2(ab - c)
  D_aa = -2, D_ab = 2c, D_ac = 2b, D_bc = 2a
  H_ij = (D_i D_j - D * D_ij) / D^2
Checks:
  (i) PSD, EXACT (Sylvester, all principal minors) at the interior grid
      G = {(1/4,1/4,1/4), (1/2,1/2,1/2), (1/2,1/3,1/4), (2/5,1/5,1/10),
           (3/10,1/5,1/10)} — each grid point first certified an SPD
      frame (1-a^2, 1-b^2, 1-c^2 > 0 and det > 0, exact).
      Expected: H strictly positive definite at every grid point (classical
      log-det barrier convexity restricted to the affine slice).
      Falsifier: any principal minor < 0.
  (ii) Boundary degeneration along the path (t, t, -t), t -> 1/2^-:
      D(t) exact = 1 - 3t^2 - 2t^3; declared checkpoints t = 2/5, 9/20,
      49/100, 499/1000 -> D = 49/125, 841/4000, 44402/10^6, 4494002/10^9.
      Expected: Phi = -ln D monotone increasing without bound, and
      lambda_max(H) monotone increasing (norm ~ O(D^-2)); the metric is
      singular at the rank-deficient boundary.
      Falsifier: lambda_max bounded, or Phi non-monotone.
  (iii) Strata complementarity (Pauli convention sigma for qubit; S

      diag(0, 1/2, 1/2))

      FULL frame (axial zero band + det-0 in the 2x2 block)
        spin-1 fully mixed I/3      -> rank 3, frame = (2/3) I,
      determinant 8/27

PR-T1b (E4, local-time algebra) — Lie flow transports Jordan frames
------------------------------------------------------------------------------
Substrate: single spin-1 bond, Jordan product X o Y = (XY+YX)/2 on the
27-dim self-adjoint space (basis: the 3 Peirce blocks of P^(2), trace
basis). Unitary u = exp(i theta Sx), alpha_t(X) = u^t X u.
Checks:
  (a) DERIVATION: ||[A, B o C] - [A,B] o C - B o [A,C]|| == 0 exactly
      for the test family {A,B,C} = {Sx, Sy, Sz, SxSy, SzSx, SxSySySz}
      (Fraction-converted after float construction; tolerance 1e-12).
      Falsifier: residual > 1e-12.
  (b) JORDAN AUTOMORPHISM: alpha_t(B) o alpha_t(C) - alpha_t(B o C)
      == 0 exactly for theta = 0.3, 0.7, 1.1 and all pairs from the test
      family. Falsifier: residual > 1e-12.
  (c) NON-INVERSE: (A o [B,C]) - [A o B, C] - [B, A o C] == (CAB - BAC)/2
      != 0 for at least one test triple (the converse derivation fails;
      this is the directedness seed). Falsifier: identically zero.
  Declared: this is the two-clock consistency LEMMA in miniature — the
  Lie flow (global clock) transports Jordan frames (local correlational
  structure) EXACTLY, so local clocks defined on Jordan sub-sectors are
  carried along the global flow without distortion. The cocycle
  (overlap agreement up to monotone reparametrization) remains an open
  lemma, registered, NOT certified here.
