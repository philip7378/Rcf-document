2.1 How Position Is Forced Without a Container: Existence, Distance,
and Direction
--------------------------------------------------------------------
Paper I demonstrated on a concrete one-dimensional spin-1 substrate
that constraint-driven dynamics, one-way reconciliation (cov3), and
universal causal extension rates emerge from an associative
*-algebra without being postulated. Two structural inputs, however,
were imported rather than derived: SU(2) covariance of the local
spin, and the 1D open-chain geometry (z <= 2). No-Go VIII (Sec. 3)
proves that bare spin-1 bond constraints P^(2) enforce existence —
admissibility, ker(M-hat) != {0} — only along strands with z <= 2 and
cannot branch statically into higher dimensions; No-Go VIIIb proves
that no static overload of that constraint can replace the
dynamical vertex coupling. The reconstruction problem is therefore:
which local algebra, built from relations alone, admits a branching
three-dimensional link structure while preserving the S = 1 bond
content Paper I certified?

Ask first how two admissible existences A, B in A_loc can be
differentiated at all inside (A, omega) when background coordinates
are forbidden. Relations are primitive; position is derived. Three
steps force the two axes of the derived object.

(i) Relational indistinguishability. Without external labels, A and
B are distinguishable only through their relational pairings with
other elements of A, inducing the metric quotient
X_omega = A_loc / ~_omega, where A ~_omega B iff d_omega(A, B) = 0:
two relations with zero relational separation collapse to the same
point. Existence alone does not individuate — on a homogeneous
spin-1 substrate every site carries the identical local algebra
M_3(C) and the identical marginal 1/3.

(ii) Distance, the first axis. Differentiating coincident from
separated existences requires a symmetric relational invariant: the
correlation decay along links. On the certified AKLT kernel this is
exact: the static two-point function obeys the closed form
<S_z^0 S_z^n>_K = (-1)^n (4/3^{n+1}) (n >= 1), a multiplicative law
of base exactly 1/3 with alternating sign, so the 1D log-distance
d(n) = n ln 3 is exactly additive per bond (r6.1 CHK-3a; closed form
machine-confirmed at L = 6, 7 with vanishing finite-size tails).
Note the object discipline: this kernel correlation (base 1/3) and
Paper I Theorem 8's dipole-channel extension rate 2/3 per reconciled
locality are two different certified multiplicative laws on two
different maps — the static kernel transfer and the operator-blind
extension map — and every distance statement in this paper names
which object it cites.

(iii) Direction, the second axis. Scalar distance from one anchor
cannot differentiate equidistant existences B_1, B_2 with
d(A, B_1) = d(A, B_2). Distinguishing them requires a signed
relative orientation. This is not a soft argument: PR-SCALE-1 (E4)
proves algebraically that unsigned pairwise kernels cannot even
separate a non-degenerate three-dimensional configuration
(det C = 1/2) from a collapsed coplanar one (det C = 0) — all eight
sign frames at |a| = |b| = |c| = 1/2 share the identical unsigned
pairwise kernels {1/4, 1/4, 1/4} and split only by the
gauge-invariant three-point orientation sign sgn(abc).

The two axes are already latent in the corpus at link level: the
distance profile Phi_A(X) := d_omega(A, X) and the displacement
profile Delta_{A->B}(X) := Phi_B(X) - Phi_A(X). A single link
dimension encodes all three primitives at once — presence
(existence), magnitude (distance), sign (direction) — so the
dimension question is exactly: how many independent 1D link
directions can close consistently inside a complex associative
*-algebra?

2.2 Theorem II.1: Complex Associative Closure Uniquely Forces
D_loc = 3 and Derives SU(2) [E4]
--------------------------------------------------------------------
Formalize a local Jordan link algebra built from D independent
directions — each carrying existence (1), distance (r), and signed
direction (+/- u-hat) — as the rank-2 Euclidean Jordan spin factor

    J_D := R 1 (+) R^D,
    (x_0, s) o (y_0, t) = (x_0 y_0 + s.t,  x_0 t + y_0 s).

Every element X = (x_0, s) satisfies the universal degree-2
characteristic identity

    X^2 - 2 x_0 X + (x_0^2 - |s|^2) 1 = 0,

with Jordan determinant det_J(X) = x_0^2 - |s|^2.

Declared Algebraic Input (M_n(C) saturation fence). Require J_D to
saturate the self-adjoint part H_n(C) = {X in M_n(C) : X^dag = X} of
a simple finite-dimensional complex associative unital *-algebra
M_n(C), so that the orthogonal Lie-Jordan split
AB = A o B + (1/2)[A, B] (Paper I, Eq. 1) closes on the same space
without leaking into higher-grade Clifford blades and carries a
non-trivial Lie sector. This saturation condition rules out real
H_2(R), quaternionic H_2(H), and proper Clifford subalgebras as a
declared primitive input — a property-level requirement, not a
container count.

integers D >= 1 and n >= 1, J_D ~= H_n(C) as Euclidean Jordan
algebras if and only if (D_loc, n) = (3, 2). Consequently:

1. Dimension elimination. Real dimension matching requires
   D + 1 = n^2. For n = 1 (D = 0) the algebra is trivial; for
   n >= 3, H_n(C) has Jordan degree n >= 3 — verified explicitly at
   n = 3 by the diagonal witness X = diag(1, omega, omega^2),

   All D in {1, 2, 4, 5, 6, 7} fail D + 1 = n^2 directly
   (certificate C4); the only solutions of D + 1 = n^2 are
   (D, n) = (3, 2) and (8, 3) (certificate C1), and the (8, 3)
   branch is eliminated by the degree invariant. (D = 1 is

2. Exact Pauli Jordan isomorphism at (D_loc, n) = (3, 2). The map
   (x_0, s) |-> x_0 1_2 + s.sigma in H_2(C) is an exact Jordan

   Jordan automorphism group of H_2(C) is
   Aut_0(H_2(C)) ~= SU(2)/Z_2 ~= SO(3), acting on s in R^3 by exact
   Rodrigues rotations: U(s.sigma)U^dag = (R_U s).sigma with residual
   9.46e-16 (certificate C3).
